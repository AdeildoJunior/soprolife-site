# SoproLife Medical Docs & POP

Use esta skill para documentos operacionais, POPs, protocolos, textos médicos institucionais e materiais técnicos da SoproLife.

## Escopo

- POP de espirometria.
- Protocolos operacionais.
- Checklists.
- Documentos para equipe.
- Documentos para parceria.
- Textos explicativos para pacientes e clínicas.

## Regras médicas

- Usar linguagem técnica quando o público for profissional.
- Usar linguagem simples quando o público for paciente.
- Não prometer diagnóstico.
- Não substituir avaliação médica.
- Não inventar norma, guideline, resolução ou exigência.
- Quando envolver norma atual, SBPT, CFM, ANVISA, legislação ou guideline, pesquisar/verificar fonte atual antes de afirmar.

## Privacidade

- Nunca incluir paciente real, CPF, telefone, laudo, pedido médico ou observação clínica privada em exemplos commitáveis.
- Usar exemplos fictícios evidentes, como `TESTE - APAGAR`.

## POP de espirometria

Sempre considerar:
- identificação do paciente;
- conferência de pedido/indicação quando aplicável;
- contraindicações e critérios de segurança;
- preparo do paciente;
- higienização;
- filtros e bocais;
- calibração/verificação do equipamento conforme fabricante;
- execução técnica;
- critérios de aceitabilidade e reprodutibilidade;
- registro, laudo e arquivamento;
- conduta em intercorrências.

## Regra de segurança documental

Quando gerar documento oficial:
- separar minuta de versão final;
- marcar pontos que dependem de validação médica/jurídica;
- não apresentar como norma obrigatória sem fonte.
