# Modelos de Planilhas — Painel SoproLife

Esta pasta contém apenas modelos vazios em CSV.

Use estes arquivos como referência para criar planilhas privadas no Google Sheets.

Não preencher estes CSVs com dados reais.

Dados reais devem ficar em:
- Google Sheets privado;
- CRM privado;
- banco de dados privado;
- pasta local ignorada pelo Git.
